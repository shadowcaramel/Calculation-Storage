ХРАНИЛИЩЕ РАСЧЁТОВ
==================

Общая библиотека результатов расчётов (значения, графики
и происхождение). Пользуйтесь Google Drive for desktop, а не только сайтом.

ОТКРЫТИЕ КАТАЛОГА
  ООТКРОЙТЕ  index.html  в этой папке (современный пайплайн).
  Не открывайте файл через предпросмотр на сайте Google Drive (страница
  будет без стилей).


ХРАНЕНИНИЕ ФАЙЛОВ НА ДИСКЕ (Windows и macOS)
  Эта папка должна быть настоящей локальной копией, с оффлайн-доступом, а не облачной заглушкой.  
  Правый щелчок по папке -> Включить оффлайн-доступ.
  Дождитесь, пока завершится синхронизация.

MACOS + CHROME
  Страница без стилей или Access denied на файлах бандлов: Chrome не может
  читать соседние файлы на томе Drive File Provider.
  Safari обычно работает без дополнительных настроек.
  Для Chrome:
    System Settings -> Privacy & Security -> Files and Folders
    -> разрешите Google Chrome.
    Если всё ещё не работает: Full Disk Access -> добавьте Google Chrome,
    полностью закройте Chrome (Cmd-Q), откройте снова, затем
    File -> Open File... и выберите index.html.

ЧТО РЕДАКТИРОВАТЬ
  annotations.toml и comparisons.toml правятся вручную.
  Не редактируйте index.html, legacy.html, site/, catalog.* и книгу Excel;
  они пересобираются.

CALCULATION STORAGE
===================

Shared library of nuclear-structure calculation results (values, plots,
and provenance). Use Google Drive for desktop, not only the website.

OPEN THE CATALOG
  Double-click  index.html  in this folder (modern pipeline).  
  Do not use the Google Drive website preview (it will look unstyled).
  

KEEP FILES ON DISK (Windows and macOS)
  This folder must be a real local copy, not a cloud placeholder.
  Drive for desktop: prefer Mirror files over Stream files.
  Right-click this folder -> Available offline / Download now.
  Wait until cloud icons become checkmarks.   

MACOS + CHROME
  Unstyled page, or Access denied on bundle files: Chrome cannot read
  sibling files on the Drive File Provider volume.
  Safari usually works with no extra settings.
  For Chrome:
    System Settings -> Privacy & Security -> Files and Folders
    -> allow Google Chrome.
    If it still fails: Full Disk Access -> add Google Chrome, quit
    Chrome fully (Cmd-Q), reopen, then File -> Open File... and choose
    index.html.

WHAT TO EDIT
  annotations.toml and comparisons.toml are hand-edited.
  Do not edit index.html, legacy.html, site/, catalog.*, or the Excel workbook;
  they are regenerated.
