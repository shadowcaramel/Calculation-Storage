CALCULATION STORAGE
===================

Shared library of nuclear-structure calculation results (values, plots,
and provenance). Use Google Drive for desktop, not only the website.

OPEN THE CATALOG
  Double-click  index.html  in this folder (modern pipeline).
  Old-code results: double-click  legacy.html.
  Do not use the Google Drive website preview (it will look unstyled).
  

KEEP FILES ON DISK (Windows and macOS)
  This folder must be a real local copy, not a cloud placeholder.
  Drive for desktop: prefer Mirror files over Stream files.
  Right-click this folder -> Available offline / Download now.
  Wait until cloud icons become checkmarks.
  Enable Shared drives for your account in Drive preferences  

MACOS + CHROME
  Unstyled page, or Access denied on bundle files: Chrome cannot read
  sibling files on the Drive File Provider volume.
  Safari usually works with no extra settings.
  For Chrome:
    System Settings -> Privacy & Security -> Files and Folders
    -> allow Google Chrome.
    If it still fails: Full Disk Access -> add Google Chrome, quit
    Chrome fully (Cmd-Q), reopen, then File -> Open File... and choose
    index.html.

WHAT TO EDIT
  annotations.toml and comparisons.toml are hand-edited.
  Do not edit index.html, legacy.html, site/, catalog.*, or the Excel workbook;
  they are regenerated.
